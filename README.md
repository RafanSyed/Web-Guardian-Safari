# Web Guardian iOS (Pure Path)

Web Guardian iOS is a native iOS wrapper designed to deploy and manage the **Pure Path** Safari Web Extension on Apple devices. 

The project name **Pure Path** reflects its core utility: helping users maintain a clean, focused, and distraction-free browsing experience by eliminating unwanted web content directly inside Safari.

## Overview

- **App Name:** Web-Guardian-IOS
- **Extension Name:** Pure Path
- **Platform:** iOS / iPadOS (Safari Web Extension)
- **Primary Function:** Local web filtering and URL parameter analysis for enhanced digital focus.

## Key Features

- **Native Safari Integration:** Runs natively as a Safari Web Extension using standard declarative filtering and local navigation rules.
- **Privacy-First Architecture:** Processes web content locally on-device without tracking user browsing history or personal activity.
- **Focus & Distraction Control:** Assists users in sticking to a intentional online path by filtering distracting or restricted domain elements.
